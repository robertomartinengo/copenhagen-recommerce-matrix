Sfruttando un modello matematico multi-criterio (**Circular Potential Index - CPI**), la piattaforma analizza flussi di rifiuti tessili, dati socio-demografici (densità Gen Z e potere d'acquisto) e vuoti di mercato per identificare le aree a più alto potenziale d'impatto economico ed ecologico.

## 🧮 𝑴𝒂𝒕𝒉𝒆𝒎𝒂𝒕𝒊𝒄𝒂𝒍 𝑴𝒐𝒅𝒆𝒍: 𝑪𝒊𝒓𝒄𝒖𝒍𝒂𝒓 𝑷𝒐𝒕𝒆𝒏𝒕𝒊𝒂𝒍 𝑰𝒏𝒅𝒆𝒙 (𝑪𝑷𝑰)

*𝑰𝒍 𝒑𝒖𝒏𝒕𝒆𝒈𝒈𝒊𝒐* **CPI** ($0.0 - 10.0$) *𝒗𝒊𝒆𝒏𝒆 𝒄𝒂𝒍𝒄𝒐𝒍𝒂𝒕𝒐 𝒊𝒏 𝒕𝒆𝒎𝒑𝒐 𝒓𝒆𝒂𝒍𝒆 𝒎𝒆𝒅𝒊𝒂𝒏𝒕𝒆 𝒖𝒏𝒂 𝒄𝒐𝒎𝒃𝒊𝒏𝒂𝒛𝒊𝒐𝒏𝒆 𝒑𝒆𝒔𝒂𝒕𝒂 𝒅𝒊 𝒕𝒓𝒆 𝒑𝒊𝒍𝒂𝒔𝒕𝒓𝒊 𝒇𝒐𝒏𝒅𝒂𝒎𝒆𝒏𝒕𝒂𝒍𝒊:*

$$\text{CPI} = (w_1 \cdot \text{Supply Score}) + (w_2 \cdot \text{Demographics Score}) + (w_3 \cdot \text{Market Gap Score})$$

* **Supply Score ($w_1 = 0.40$):** Densità di rifiuti tessili e volume di materiale recuperabile annuo (t/anno).
* **Demographics Score ($w_2 = 0.35$):** Concentrazione del target Gen Z/Millennials e reddito medio disponibile (DKK).
* **Market Gap Score ($w_3 = 0.25$):** Opportunità di mercato misurata sul rapporto tra popolazione residenti e punti vendita second-hand o contenitori di raccolta già esistenti.

### 1. 🗺️ Spatial Heatmap (GeoJSON Polygonal Choropleth)
Visualizzazione geografica ad alta precisione dei confini poligonali degli 11 distretti di Greater Copenhagen e Frederiksberg con gradienti di colore adattivi basati sul punteggio CPI.

### 2. ⚔️ Side-by-Side B2B Benchmark & Radar Chart
Confronto diretto e analitico tra due distretti selezionati (*Materia Prima Tessile*, *Target Gen Z*, *Opportunità di Mercato*) tramite grafici a barre affiancate e profilo radar bidimensionale.

### 3. 📄 Automated Executive PDF Generator
Generazione dinamica in tempo reale di schede sintetiche B2B scaricabili in PDF, complete di rating metropolitano, suddivisione dei pilastri e raccomandazioni strategiche per l'apertura retail.

### 4. 🤖 Freemium Telegram Bot Assistant
Interfaccia conversazionale diretta pensata per l'utente/commerciante finale:
* **Free Tier:** Consultazione immediata in chat della top zona e degli indicatori chiave.
* **Premium Tier:** Generazione e invio automatico del Report Executive PDF completo in chat.

## 🚀 𝑮𝒆𝒕𝒕𝒊𝒏𝒈 𝑺𝒕𝒂𝒓𝒕𝒆𝒅

### 📋 𝑷𝒓𝒆𝒓𝒆𝒒𝒖𝒊𝒔𝒊𝒕𝒆𝒔
* Python `3.11+`
* Docker & Docker Compose *(opzionale per containerizzazione)*

### ⚙️ 𝑳𝒐𝒄𝒂𝒍 𝑺𝒆𝒕𝒖𝒑

1. **Clona la repository e crea il virtual environment:**
   ```bash
   git clone [https://github.com/robertomartinengo/copenhagen-recommerce-matrix.git](https://github.com/robertomartinengo/copenhagen-recommerce-matrix.git)
   cd copenhagen-recommerce-matrix
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate

2. **Installa le dipendenze:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configura le variabili d'ambiente:**
   ```bash
   cp .env.example .env
   ```
   *Inserisci i tuoi parametri reali in `.env` (`SUPABASE_URL`, `SUPABASE_KEY`, `TELEGRAM_BOT_TOKEN`).*

4. **Avvia la Control Room e l'API:**
   ```bash
   # Terminale 1 (Backend API)
   uvicorn main:app --reload --port 8000

   # Terminale 2 (Dashboard Streamlit)
   streamlit run dashboard.py
   ```
